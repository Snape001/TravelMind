# Phase 4 专家 Skills 与报告

`SkillRegistry` 按可信的 Agent ID 和执行阶段解析版本化定义。每个 `runtime/skills/definitions/*.v1.json` 文件独立声明角色、适用条件、输入输出 Schema、步骤、质量要求、工具白名单及预算。档案只引用技能 ID 和版本，读取档案不会打开定义文件。执行阶段首次选择技能时才读取文件，后续通过注册表复用该版本。运行时的 `writer` 对应档案 `report_writer`。

| 角色 | 技能与执行时机 |
| --- | --- |
| Research Director | 梳理需求与澄清。在初始简报及用户答复后调用 |
| 历史文化、自然地理、旅游资源、社交舆情、文献研究、互联网研究 | 各自使用专业研究技能。在存在属于自身的任务分工时调用 |
| 旅游规划 | 使用现有 `travel_planning` ID 评估行程和可达性 |
| Writer | 依序选择报告结构规划、证据整合、统一叙事撰写、旅游价值与全篇编辑 |
| Reviewer | 从已完成的草稿、研究简报和证据执行独立核查 |

专业研究技能使用现有 `Assignment`、`Finding` 和 `Evidence`。每次调用最多允许一次由工作流注入的 `retrieve_evidence`，已经采集资料的反思轮可直接传证据。一次调用的计数以 Runtime 工具为单位，供应商请求及其重试仍由检索层控制。Director、Writer 和 Reviewer 的外部工具额度为零。每项技能有独立上下文字符上限，输出 Token、超时及尝试次数取技能和任务设置中的较小值。超预算输入在调用模型前拒绝。日志记录任务、运行、角色、技能版本、调用 ID 及执行结果。

## 报告流程

大纲只读取简报、有限的专家发现目录、待核问题及审核意见，按主题和游客的决策顺序规划章节。完全相同的发现按内容、状态和证据合并，保留贡献者。每条发现须归入一章，超出用户范围的发现可显式省略。大纲与综合材料使用内部 Pydantic 模型。

证据整合逐章处理材料，把相近内容归到共同论点，记录适用条件、分歧和资料缺口。当前工作流提供评分结果时，只把可用证据交给 Writer。缺少可用原文的判断保留为缺口或待解释争议。章节顺序、发现归属和支持所需引用由程序检查。

初稿与全篇编辑均返回既有 `ReportDraft`。编辑检查篇章衔接、旅游价值和方向比重，在适用时写明可观察的看点、建议停留范围、游览顺序、季节和注意事项。停留建议须标为估计，具体路段耗时、运营数据及预约规则须有来源。编辑必须保留已通过结构校验的署名和引用。归档证据保持原文，模型只收到受长度限制的摘录。

独立 Reviewer 接收整篇草稿、简报及研究证据，核对关键事实、时效、主题覆盖、旅行建议和分歧。未知或低质量证据引用、无贡献者署名会直接触发返工。语义性判断仍由 Reviewer 完成。返工把审核意见送回 Writer 并重新走报告流程，次数由现有图限制。

## 集成交接

在启用 Phase 4 的工作流中组装一个 `SkillRegistry()`，向现有 `editorial.write` 与 `editorial.review` 传入 `skills=registry`。两者仍返回 `ReportResult` 和 `ReviewResult`。C 线保留当前 Worker、Planner 和公开路由，旧路径省略该参数，已有报告和 Checkpoint 继续按原格式读取。

Director 可调用 `runtime.skills.research.director_skill` 获取现有 `DirectorDecision`。专家调用 `research_skill` 可接收现有证据及工作流批准的检索器，并返回 `ResearchResult`。文献研究、互联网研究档案及技能可执行，进入正式调度需由集成工作流纳入名册。独立路线与问卷接入沿用各自支线。集成端使用同一固定版本注册表续跑同版工作流。发布新定义时新增版本文件，将版本切换与工作流选择一并管理。

## 验证

自动化测试用固定模型响应跑通 LangGraph 的四阶段写作、独立审核及返工。专项测试还覆盖惰性读取、角色和档案映射、工具与上下文限制、章节归属、争议和署名引用校验。完整回归使用执行过 Alembic 迁移的独立 PostgreSQL 14。

以泉州遗产的公开摘录和明确的预约缺口调用真实 `deepseek-flash`，四次写作调用和一次独立审核完成，生成两章、一条引用，Reviewer 返回 `approved`。供应商返回 7,126 输入 Token 和 1,540 输出 Token。该样例验证编辑链路，资料沿用已有摘录。
